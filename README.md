## Database blockers (current)

- **Migration history unknown:** `public.schema_migrations` is absent in the target database, so migration history cannot be confirmed. The migration has **not been confirmed as applied**.
- **Elevated privileges:** The configured connection role has elevated privileges (per preflight checks). A least-privilege runtime role is preferred.
- **No migration application:** Migration application remains disabled. The preflight remains read-only and no schema/data changes have been applied.
- **MVP persistence:** The discovery MVP does **not** require database persistence to run — the main workflow loads from CSV and works without a database. Database integration remains deferred.
